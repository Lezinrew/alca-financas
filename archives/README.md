# Arquivo morto

Material fora de uso, guardado só para consulta histórica. Nada aqui é lido
pelo app, pelo Docker ou pelo CI. Não use estes scripts nem guias em operação.

| Pasta | Conteúdo |
|---|---|
| `legacy/` | Guias e scripts de deploy antigos (Render, Hostinger, MongoDB, chatbot FastAPI). |
| `docs-legacy/` | Documentação do MongoDB (não usado em produção). |
| `scripts-raiz/` | Scripts que ficavam na raiz: início/parada no Mac (`alca_*.sh`), correções pontuais de servidor, `backend_test.py`, `supervisord.conf`. |
| `relatorios/` | Relatórios de diagnóstico de abril/2026 (alinhamento de runtime, hardcodes, mapa de consumo da API, memória do projeto). |

Valores de chave que existiam nos guias antigos foram substituídos por texto de
exemplo; continuam no histórico do Git. Se algum ainda estiver em uso, gere outro.
